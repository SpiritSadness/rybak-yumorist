# Если бот шлёт ошибки про бэкап или «не работает»

Это **не для обычных пользователей** — только если ты **владелец** бота и настроил его на своём компьютере/сервере.

## В чём дело

Бот может слать служебные сообщения:
- «бэкап не сделан»
- «бот не работает»

Так бывает, если компьютер выключили, перенесли проект, или бэкапы больше не нужны — а **автопроверки** всё ещё включены.

## Как выключить (одна команда)

На компьютере, где стоит бот:

```bash
cd папка-с-ботом
git pull
bash scripts/ops-disable.sh
```

Или: `./botctl.sh` → пункт **17**.

Бот **продолжит работать**. Перестанут приходить сообщения про бэкапы и падения.

## Если бот не отвечает в Telegram

```bash
./botctl.sh restart
```

Если не помогло — пункт **11** в меню (лишние копии бота) или напиши в issue.

## Включить бэкапы снова

```bash
bash scripts/ops-enable.sh
```

Или botctl → пункт **18**.
